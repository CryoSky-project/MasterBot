# SKY-CHEK BOTS SYSTEM

Бұл жоба екі негізгі Telegram боттан және оларды жүйелі түрде басқаруға арналған көмекші құралдардан тұрады.

---

## 📁 Жоба құрылымы мен Файлдар

1.  **`main.py`** - Клиенттердің төлем мерзімдерін бақылайтын, жаңа боттарды сататын және оларды тіркейтін негізгі бот (Master Billing Bot).
2.  **`database.py`** - PostgreSQL деректер базасымен жұмыс істейтін кітапхана (Users, Settings, Clients, Orders).
3.  **`dowm.py`** - Пайдаланушы жіберген видео файлдардың сапасын талдап, оларды H.264 форматында барынша кішірек көлемге (МБ) сығымдайтын бот (Video Compressor Bot).
4.  **`manage.sh`** - Екі ботты да серверде оңай басқаруға (іске қосу, тоқтату, журналдарды оқу) арналған бірыңғай скрипт.
5.  **`.env`** - Конфигурациялық баптаулар (Бот токені, әкімшілер ID-лері, Деректер базасының URL-і).

---

## 🛠️ Серверде Басқару (`manage.sh`)

Скриптке орындалу құқығы берілген: `chmod +x manage.sh`.

### Жалпы командалар форматы:
```bash
./manage.sh [command] [bot]
```

*   `[command]` - `start`, `stop`, `restart`, `status`, `logs`
*   `[bot]` - `master`, `compress`, `all` (тек logs командасы үшін `all` қолданылмайды)

### Қолдану мысалдары:
*   **Боттардың күйін тексеру:**
    ```bash
    ./manage.sh status all
    ```
*   **Негізгі ботты қайта іске қосу:**
    ```bash
    ./manage.sh restart master
    ```
*   **Видео сығымдағыш боттың журналдарын (logs) оқу:**
    ```bash
    ./manage.sh logs compress
    ```

---

## ⚙️ Жүйелік Қызметтер (Systemd Services)

Боттар фонда үзіліссіз жұмыс істеуі үшін серверде келесі қызметтер тіркелген:
*   `sky-chek.service` (Master Billing Bot)
*   `sky-compress.service` (Video Compressor Bot)

Баптаулары өзгертілген жағдайда, жүйені қайта жүктеу:
```bash
systemctl daemon-reload
```
